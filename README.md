# Claude Skills

A collection of Claude skills that I've built and found useful. Feel free to grab any of them and add them to your own Claude setup.

## What's a Claude skill?

A skill is a packaged set of instructions, scripts and references that teaches Claude how to do a specific kind of task well. Once it's installed, Claude picks it up automatically when it's relevant, or you can call it with a slash command.

## Skills in this repo

| Skill | Folder | What it does |
| --- | --- | --- |
| Low Poly Model | [`blender/lowpolymodel`](blender/lowpolymodel) | Builds stylized low-poly 3D characters (chibi humans, toy robots, mascot blobs) in Blender, with clean geometry and simple bone rigs. Run it with `/modelchar`. |

More skills will be added over time.

## How to use a skill

1. Download the skill's `.zip` file from its folder.
2. Unzip it into your Claude skills directory (for Claude Code, that's `~/.claude/skills/`).
3. Restart Claude, and the skill will be ready to use.
